# PortWatch 操作手册

版本：v0.5.0 ｜ 适用平台：Windows（Linux/macOS 部分支持，见第 8 节）

PortWatch 是一个面向开发者的端口诊断与进程管理命令行工具，核心解决两个问题：

1. **端口被谁占了** —— 查询 TCP/UDP 端口对应的 PID、进程名、命令行和可执行文件路径；
2. **怎么释放它** —— 在确认后安全地终止占用端口的进程，并验证端口已释放。

`pw` 是等价短别名（安装时额外构建一份 `pw.exe`），本文所有示例中的
`portwatch` 都可以直接替换为 `pw`。

---

## 1. 安装与验证

要求 Windows 系统和 Go 1.22 或更新版本。在项目根目录执行：

```powershell
$bin = Join-Path $env:USERPROFILE "bin"
New-Item -ItemType Directory -Force $bin | Out-Null
go build -o (Join-Path $bin "portwatch.exe") ./cmd/portwatch
go build -o (Join-Path $bin "pw.exe") ./cmd/portwatch

$userPath = [Environment]::GetEnvironmentVariable("Path", "User")
if (($userPath -split ';') -notcontains $bin) {
    [Environment]::SetEnvironmentVariable(
        "Path",
        (($userPath.TrimEnd(';') + ';' + $bin).Trim(';')),
        "User"
    )
}
```

关闭并重新打开 PowerShell，验证安装：

```powershell
Get-Command portwatch
portwatch --version
portwatch 8080
```

> **权限提示**：查询或终止进程时如果出现 `access denied`，请关闭当前窗口，用“以管理员身份运行”的 PowerShell 重试。

## 2. 快速上手（最短路径）

```text
场景：8080 端口被占用，想找到并释放它

portwatch 8080        # 1. 查看谁占了 8080（PID、进程名、路径）
portwatch info <PID>  # 2. （可选）查看该进程详情和它占用的所有端口
portwatch free 8080   # 3. 释放端口，输入 y 确认
```

`free` 会先显示进程详情并要求输入 `y` 或 `yes`；直接回车或输入其他内容都会取消操作。终止成功后会重新扫描端口，确认已释放。

## 3. 查询端口

| 命令 | 作用 |
| --- | --- |
| `portwatch 8080` | 查询单个端口 |
| `portwatch 3000-4000` | 查询端口范围 |
| `portwatch --ports 3000,8080,8848` | 查询指定端口集合 |
| `portwatch` | 列出全部 TCP `LISTENING` 端口 |
| `portwatch --protocol udp` | 查看 UDP 绑定端口（仅 Windows） |
| `portwatch --protocol all` | 同时查看 TCP 和 UDP（仅 Windows） |
| `portwatch --process node` | 只看名称包含 node 的进程的端口 |
| `portwatch --pid 1234` | 只看指定 PID 的端口 |
| `portwatch --state LISTENING` | 按连接状态筛选 |

**注意**：全局选项（如 `--json`、`--protocol`）必须放在位置参数或子命令之前，写 `portwatch --json 8080`，不要写 `portwatch 8080 --json`。

---

## 4. 进程查询与详情

| 命令 | 作用 |
| --- | --- |
| `portwatch find node` | 搜索名称包含 `node` 的进程 |
| `portwatch info 1234` | 查看 PID 1234 的详情及其占用的所有端口 |

---

## 5. 终止进程与释放端口

| 命令 | 作用 |
| --- | --- |
| `portwatch free 8080` | 释放端口：显示占用进程详情 → 输入 `y`/`yes` 确认 → 终止 → 重新扫描验证 |
| `portwatch kill 1234` | 按 PID 直接终止进程（同样需要确认） |

安全边界：

- 所有终止操作都需要交互式确认，不存在“无提示直接杀进程”的路径。
- 终止后 PortWatch 会验证 PID 已退出、端口已释放。
- 关键系统 PID 会被拒绝终止（退出码 5）。

---

## 6. 实时监听（watch）

| 命令 | 作用 |
| --- | --- |
| `portwatch --interval 2s watch` | 每 2 秒报告新增或移除的监听端口，Ctrl+C 退出 |
| `portwatch watch 8080` | 只监控单个端口 |
| `portwatch --json watch` | 以 JSON Lines 输出变化事件，适合脚本消费 |

`--interval` 支持Go 时间格式，如 `500ms`、`2s`、`1m`。

## 7. JSON 输出（脚本集成）

在任何查询命令前加 `--json` 即可得到稳定 JSON，例如：

```powershell
portwatch --json 8080
portwatch --json find node
portwatch --json info 1234
```

JSON 契约要点：

- 顶层包含 `schema_version`，端口结果当前为 `"2"`；脚本应先检查版本再读取新增字段。
- 端口结果可能包含可选的 `service` 对象（如 `name: "Vite"`），无法识别时显示 `Unknown`。
- 空结果使用空数组：`{"schema_version":"2","ports":[]}`。
- `--json watch` 使用 JSON Lines，每行一个独立事件对象，包含 `event`、`observed_at`、端口、协议、PID 和进程名。
- `--json info <pid>` 使用独立的进程详情 schema（当前 `"1"`），返回 `process` 对象及其 `ports` 数组。

### 退出码

| 退出码 | 含义 |
| --- | --- |
| `0` | 查询成功、空结果、用户取消或 Ctrl+C |
| `2` | 参数、端口、PID 或筛选条件无效 |
| `3` | 扫描或进程信息读取失败 |
| `4` | 权限不足 |
| `5` | Kill 失败、关键 PID 拒绝或 Kill 后验证失败 |

## 8. 交互式终端界面（TUI）

启动方式：

```powershell
portwatch tui          # 默认进入 TCP LISTENING 视图
portwatch tui 8080     # 聚焦单个端口
```

TUI 默认只显示 TCP `LISTENING` 端口，最短操作路径：

```text
Up/Down 选择端口（方向键异常时，u 上移、j 下移）
Enter   查看详情
K       打开终止确认
Enter   确认，Esc 取消
```

常用按键：

| 按键 | 作用 |
| --- | --- |
| `/` | 按端口、PID 或进程名过滤 |
| `R` | 手动刷新 |
| `V` | 切换视图：Listening / Connections / All |
| `?` | 查看完整帮助 |
| `Q` | 退出 |

终止进程后 PortWatch 会验证 PID 已退出并检查端口是否释放。遇到 `Access denied` 时请用管理员权限重新打开 PowerShell。

## 9. 平台差异说明

| 平台 | 实现方式 | 支持范围 |
| --- | --- | --- |
| Windows | IP Helper API + 进程 API（直读 PEB 进程参数，不 spawn PowerShell） | TCP 监听端口 + UDP 绑定端口，全功能 |
| Linux | `/proc` | 当前仅 TCP；UDP 返回明确的不支持错误 |
| macOS | `lsof` / `ps` | 当前仅 TCP；UDP 返回明确的不支持错误 |

Linux/macOS 的实现已包含在代码中，但建议在目标系统上单独验证权限和相关命令的可用性。

## 10. 常见问题

**Q：查询/终止时提示 `access denied`？**
用管理员身份重新打开 PowerShell。

**Q：`--json` 放在端口后面没生效？**
全局选项必须放在位置参数或子命令之前：`portwatch --json 8080`。

**Q：TUI 里方向键不能用？**
使用备用键位：`u` 上移、`j` 下移。

**Q：怎么看退出码（脚本中）？**
PowerShell 中执行命令后查看 `$LASTEXITCODE`，含义见第 7 节退出码表。

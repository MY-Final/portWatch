# PortWatch V3 PRD

## 1. 版本定位

V3 在 V2 稳定 CLI、TUI 和 JSON 合同的基础上，扩大端口诊断覆盖范围，仍保持工具简单、可脚本化、跨平台实现隔离。

## 2. 已进入实现的第一项

### 端口范围查询

命令：

```powershell
portwatch 3000-4000
portwatch --json 3000-4000
```

要求：

- 范围格式为 `START-END`
- 两端均为 1 到 65535 的整数
- `START` 不得大于 `END`
- 结果复用当前 TCP 扫描、进程信息、服务识别和 JSON schema `2`
- 输出按端口、PID 稳定排序
- 空范围结果输出合法空 JSON 数组或带表头的空表
- 单端口命令行为保持不变

无效示例必须返回参数错误：

```text
portwatch 0-80
portwatch 4000-3000
portwatch 80-
```

## 3. 后续范围

V3 后续候选：

- `--ports 3000,8080,8848` 端口集合查询
- Windows UDP 扫描和 `--protocol tcp|udp|all`
- JSON watch 事件输出
- 端口状态过滤和进程详情增强

这些候选在独立 PRD 和任务拆分完成前不应与范围查询混合实现。

## 4. 非目标

V3 仍不做数据库、后台服务、Web UI、AI、MCP、自动 Kill 或网络流量抓包。
